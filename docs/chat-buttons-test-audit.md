# 聊天按鈕與測試整理（2026-10-18）

## 檢查結論

BC-LCE 的指令／房間按鈕已透過 createElement、dataset、textContent 處理文字，提示框也使用 textContent；未發現舊版獨立 Chat TtoB 的 HTML 字串注入問題。沒有必要整份替換或移植獨立版程式。

這次針對實際問題調整：

- 關閉 commandButtons 時，立即隱藏提示框並以文字節點還原自己建立的按鈕，保留空白、引號與旁邊既有連結。
- 移除 processedText／lceDone 雙重快取。共用聊天 pipeline 已按 DOM 變動增量處理；只比較 textContent 會漏掉文字相同但節點已重建的情況。
- 獨立 Chat TtoB 啟用時讓它負責轉換；停用後恢復 LCE。略過對方建立的 span，避免重複包裝。共存狀態由既有 500ms pipeline 偵測，不另加輪詢。
- 設定關閉後只在狀態切換時還原，不每 500ms 掃描全部訊息。快速關閉再開啟也會立即重新處理。
- 離開聊天室隱藏提示框。LCE 的聊天模組仍屬整個插件的一次性安裝，未另造一套整個 LCE 的卸載介面。
